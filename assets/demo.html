今天想让我帮你做点什么？
试试给 DSH 换一张背景图：点左侧「皮肤」→「选择图片」→「应用」，就能把任意图片变成全屏磨砂背景。dsh-wx-skin 支持本地图片与 URL。
pnpm dsh plugin --profile web add file:dsh-wx-skin-0.1.0.tgz
一行命令即可安装。
能把我的 4K 壁纸也应用上吗？
当然可以，图片大小没有限制；「透出」滑杆可以调节背景的明显程度，明暗主题也会自动适配。
